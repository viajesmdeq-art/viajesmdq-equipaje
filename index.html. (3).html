Cobrar por código de grupo

Buscá el código único del pasajero. El sistema reúne todos sus bultos, calcula la deuda total y permite combinar efectivo, transferencia, débito o crédito en un mismo cobro. La transferencia suma un 3,5% sobre el importe asignado a ese medio.

Ingresá el código impreso en el comprobante del pasajero.
Ingresá un código de grupo para ver los bultos y el saldo pendiente.
